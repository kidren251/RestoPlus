# Resto Plus / PalaceOS

Solution mobile bi-espace (Opérationnel / Académie) pour l'hôtellerie et la restauration de luxe.

## Démarrer

```bash
yarn install
yarn dev:mobile   # lance l'app Expo
yarn dev:api      # lance l'API Fastify
```
